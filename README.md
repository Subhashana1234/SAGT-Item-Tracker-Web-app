# SAGT-Item-Tracker-Web-app
Built a web application to track items sent for external repair, replacing a manual Excel sheet with one centralized system shared by the Stores and Procurement teams at SAGT, Port of Colombo.

🔹 PROBLEM
Repair items were tracked in Excel, which caused duplicate data entry, poor visibility and missed follow-ups on delayed items.

🔹 WORKFLOW
1️⃣ Stores raises a repair request (Gate Pass, WO, POR, supplier, qty)
2️⃣ Procurement moves it through Quotation → Approval → Purchase Order
3️⃣ Item is sent for external repair
4️⃣ Stores records receiving and inspection, including partial deliveries

🔹 KEY FEATURES
✅ Role-based login for Stores and Procurement
✅ Automated dashboard with KPIs, status charts and supplier workload
✅ Overdue tracking that shows how many days each item is late
✅ Urgent and Warranty/FOC tagging
✅ Searchable Master View with filters and CSV export
✅ Notifications between teams
✅ Validation, such as blocking over-receiving
✅ Dark mode and responsive design

🔹 TECH STACK
React.js • HTML • CSS • Tailwind CSS • PHP • MySQL • XAMPP (Apache) • Antigravity

🔹 MY ROLE
Designed the MySQL database and PHP backend for requests, approval decisions and item status. Built the React interface and the dashboard.

🔹 IMPACT
✔ One shared record for every team
✔ Less manual work and duplicate entry
✔ Faster follow-up on overdue repairs
